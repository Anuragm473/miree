# 💫 Happy Birthday, Miree — React surprise site

Five animated scenes (mobile + desktop): **Same sky → 22 cards → Photo polaroids → Birthday cake → Love letter & "Open when…" notes**.

## Customise (everything is in `src/config.js`)
- Names, age, every message, all 22 cards, captions, the letter, the "open when" notes.
- Photos: copy images into `public/photos/` and set `src: '/photos/1.jpg'`. Empty `src` shows a placeholder.

## Run
```bash
npm install
npm run dev      # test on your phone via the Network URL it prints
npm run build    # outputs /dist
```
